I was working on a digital point and shoot camera using a raspberry pi. You have to realise that a raspberry pi is a tiny computer has GPIO pins (GPIO stands for General Purpose Input Ouput) where you can connect buttons and motors to the pi. I had bought a shutter button and a screen for this project but AFTER buying all the stuff I realised that THE SCREEN USED ALL THE PINS AND SO THE BUTTON COULDN'T BE USED!!! This was very frustrating and this also meant that I had to work around that problem.
